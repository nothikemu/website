# UX profile: hkmu.me

Read this before changing layout, colour, type or motion. The vectorlab UX skills and the
frontend-design skill read it too.

## Subject

hikemu's corner of the internet. One page, reached from a Discord / X / GitHub bio link.
Its job: show who hikemu is and what they're up to right now (Discord presence, music),
with enough personality that it's worth bookmarking. Not a portfolio, not a dashboard.

Composition is fixed by the original brief (a reference screenshot): profile + now playing on
top, the mascot in the gap, About Me + Recent Streams below, Projects last.

## Page pattern

Marketing route type **About** (tell the story), adapted to the brief: profile + now playing as
the story hero, then About Me, Recent Streams and Projects, then the footer. No nav bar: the
brief asks for a single page with no tabs, like schuh.wtf. Recent Streams and Projects reuse List
ideas (search, framed well with hairlines, resting affordance on clickable rows).

## Aesthetic

Custom. Calm, moonlit, terminal-adjacent. Closest reference for motion: Stripe / Notion
(150–200ms, restrained). One memorable element: Sakamoto-san (fan art) sitting on the
Recent Streams panel, whose red scarf is the only warm colour on the page.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| `--ink` | #0e1220 | L0 canvas (60%) |
| `--slate` | #151b2c | L1 panels (30%) |
| `--well` | #10162a | inset list wells inside panels |
| `--raised` | #1c2338 | L2: row hover, tooltips |
| `--paper` | #ebe7dd | primary text (15.1:1 on ink) |
| `--fog` | #a6acbb | secondary text (7.5:1 on slate) |
| `--dusk` | #8a91a3 | meta text (5.4:1 on slate) |
| `--moon` | #b3beff | the single interactive accent: links, focus, active (10%) |
| `--scarf` | #e5483f | Sakamoto's scarf only (illustration, not UI) |

Semantic, used only where they carry meaning: Spotify green #1ed760 (Spotify mark and "live"),
Discord status colours (online / idle / dnd / offline).

Elevation: 1px border at 8% white first, plus a top-edge inset highlight. Shadows stay diffuse.
Lists and tables sit in a `--well` with a border and hairline row dividers.

## Type

One family: JetBrains Mono Nerd Font (self-hosted subset, OFL). Weights 400 / 500 / 600 only.

| Role | Size | Line-height |
| --- | --- | --- |
| meta (timestamps, durations, counts) | 12px | 1.4 |
| secondary (list rows, prose in panels) | 14px | 1.55 |
| body | 16px | 1.55 |
| panel title | 18px / 600 | 1.25 |
| now playing title | 20px / 600 | 1.25 |
| name | 24px / 600 | 1.2 |

Nothing below 12px. 88x31 badges are images (text outlined into the SVG) and carry alt text.
Panel titles keep the brief's wording ("About Me", "Recent Streams", "Listening to Spotify").

## Spacing

4 / 8 / 12 / 16 / 24 / 32 / 48. Panel padding 24 (16 on narrow). Grid gap 16.

## Viewports

narrow < 768 (single column), medium 768+, wide prove at 1280. `main` is capped; nothing else.

## Touch / focus

WCAG 2.1 AA. Hit targets 44x44. Focus ring: 2px `--moon`, 2px offset.

## Voice

Lowercase, casual, slightly weird, plain verbs. Errors never blame and always offer a next step.
No middle-dot meta strings, no arrows appended to links, no all-caps labels.

## Motion

Tokens 100 / 150 / 200 / 300ms. Enter ease-out, exit ease-in. transform + opacity only.
One orchestrated page-load moment; no fade-up per section, no hover glow on static panels.

Documented exceptions (functional or user-driven, all off under reduced motion):
- playback progress bar: linear over the song's length (it is the song's progress)
- equaliser bars and Sakamoto's music notes loop only while music is actually playing (live activity)
- Sakamoto's eyes follow the pointer (user-driven), and he blinks at random 4–9s intervals while visible
- banner parallax follows the pointer by a few px (user-driven)
- the refresh icon spins (600ms linear) only while a refresh is in flight and slower than 100ms (`aria-busy`)

## Banned

Glassmorphism, rainbow gradients, decorative pills on static text, hover effects on
non-interactive panels, cartoon empty states, infinite decorative loops, `title` used as a tooltip.
